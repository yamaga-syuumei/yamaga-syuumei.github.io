ブランドサイトをGitHub Pagesで公開しました

作品はDLsite、FANZA、小説投稿サイトにばらばらに置いてあって、「山賀秀明が何を作っているのか」を一枚で見せる場所がありませんでした。作る方には時間を注いできましたが、届ける方が手薄だったという自覚があります。その最初の一手として、自分のサイトを作りました。

公開したのはこちらです。

https://yamaga-syuumei.github.io/

何もインストールせずに作る

まず決めたのが「新しいものを入れない」でした。開発環境はできるだけ汚したくありません。何かを試すたびにPATHが増えて、あとから何が入っているのか分からなくなるのが嫌だからです。

結論から言うと、gitだけで足りました。Node.jsもnpmも要りません。

今どきのサイト作りはフレームワークから入るのが普通ですが、あれはMarkdownを自動でHTMLに変換したり、記事一覧を生成したりするための道具です。ページが数枚なら、HTMLを直接書いた方が速いし、壊れる余地もありません。

  • HTMLとCSSを書く
  • gitでコミットする
  • GitHubにpushする

これだけで公開されます。ビルド工程がないので、pushした1〜2分後には反映されています。

ユーザーサイト方式を選んだ

GitHub Pagesにはリポジトリ名の付け方が2通りあって、URLの形が変わります。

  • <ユーザー名>.github.io → https://ユーザー名.github.io/
  • 任意の名前 → https://ユーザー名.github.io/リポジトリ名/

前者を選びました。URLが短いのと、あとで独自ドメインに移すときに素直だからです。後者は/リポジトリ名/が挟まる分、画像やCSSのパス指定で事故りやすいという話も聞きます。

前者はアカウントにつき1つしか作れませんが、後者は無制限です。今後WEBゲームを公開するときは、ゲームごとにリポジトリを分けて/ゲーム名/にぶら下げる予定です。1本が壊れても本体が巻き込まれません。

成人向け作品をどう扱うか

ここが一番考えたところです。うちはゲーム7本のうち6本が成人向けなので、扱いを間違えるとサイトとして成立しません。

結論として、全年齢ページと成人向けページを完全に分け、後者に年齢確認を挟みました。

実装で気をつけたのは、JavaScriptが無効でも中身が漏れないようにすることです。よくあるのは確認ダイアログを上から被せるやり方ですが、あれはJSを切ると背後の中身が読めてしまいます。そこで逆に、CSSで最初から中身を非表示にしておき、確認が取れて初めて表示される形にしました。

#site { display: none; }
body.verified #site { display: block; }

JSが動かない環境では、確認画面のまま止まります。

GitHubの規約を実際に読んでみた

気になったので、成人向けの扱いについて条文を確認しました。「成人向けは全部ダメ」だと思い込んでいたのですが、そうではありませんでした。

当社は、裸体または性に関するコンテンツがすべてわいせつであると認識しているわけではありません。（中略）ただし、当社では、表示する前にオプトインする選択肢をユーザーに提供して、コンテンツを制限できるようにしています。

禁止されているのは「性行為のあからさまな描写」で、これには画像だけでなくテキストも含まれます。一方で、表示前のオプトイン、つまり年齢確認を挟む方法はGitHub自身が挙げている対処法でした。作品名とストアへのリンクだけなら問題ありません。

ただしパッケージ画像は別です。年齢確認は「訪問者に見せない」仕組みであって、「サーバーに置かない」仕組みではありません。ファイルとして置いた時点でアウトなので、成人向け作品のサムネイルは掲載を見送りました。露出のない差し替え版ができたら足していきます。

つまずいた2つ

1つめ。pushしたら403で弾かれました。

remote: Permission to yamaga-syuumei/... denied to i-horse.
fatal: ... The requested URL returned error: 403

Windowsの資格情報マネージャーに昔使った別アカウントの認証情報が残っていて、gitが勝手にそちらで認証していました。資格情報を消して入れ直せば直ります。リモートURLにhttps://ユーザー名@github.com/...とアカウント名を埋め込んでおくと、以後混ざりにくくなります。

2つめ。DLsiteのサークルページは全作品を出してくれません。

作品一覧を作るのにサークルプロフィールページを見て回っていたのですが、AI生成フロアのページが3作品あるうち1件しか表示していませんでした。「1件中1～1件目」と書いてあるので、そこで全部だと思い込んでいました。サークル名で検索したら7件出てきました。フロアをまたぐ場合は検索の方が確実です。

これから
