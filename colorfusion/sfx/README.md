# 効果音の置き場所

ここに音声ファイル（mp3 / ogg / wav）を置いて、
`../sound.js` の `SFX_FILES` にファイル名を書くと鳴りはじめます。

| キー | 鳴る場面 |
|---|---|
| `fuse` | 同じ色が融合した。連鎖が伸びるほど自動で高くなります |
| `chain` | 連鎖が x3 以上で終わった |
| `absorb` | コアが吸い込んだ。大きいほど自動で大きくなります |
| `stage` | 段が変わった |
| `lap` | 次の周に入った |
| `start` | ランの開始 |
| `over` | 光が尽きた |

書き方：

```js
var SFX_FILES = {
  fuse: 'sfx/se_fuse.mp3',
  ...
};
```

空文字のままの音は鳴りません（エラーにもなりません）。

**素材をもらったら `sound.js` の `CREDITS` に出どころを書いてください。**
設定パネルの「音の素材」にそのまま出ます。
