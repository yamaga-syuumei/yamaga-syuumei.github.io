# BGMの置き場所

ここに音声ファイル（mp3 / ogg）を置いて、
`../sound.js` の `BGM_FILES` にファイル名を書くと鳴りはじめます。

| キー | 流れる場面 |
|---|---|
| `title` | タイトル画面とデモ |
| `play` | プレイ中 |

ループ再生されます。切り替えは自動でクロスフェードします。

書き方：

```js
var BGM_FILES = {
  title: 'bgm/title.ogg',
  play:  'bgm/play.ogg'
};
```

空文字のままなら鳴りません（エラーにもなりません）。

**素材をもらったら `sound.js` の `CREDITS` に出どころを書いてください。**
